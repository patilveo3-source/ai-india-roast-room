# AI India Roast Room

This project is the AI India Roast Room: a council of simulated Indian advisors that debates an Indian founder's business decision, in Hinglish, with money in rupees. Twelve seats ship with it: Nithin Kamath, Sridhar Vembu, Kunal Shah, Falguni Nayar, Narayana Murthy, Uday Kotak, Aman Gupta, Anupam Mittal, Aadit Palicha and Raj Shamani (the two Gen-Z seats), Raghuram Rajan (policy and the economy), and Amitabh Bachchan (comeback and reputation). Seven sit on the default board; the rest are on call. Before each council the Chair recommends a board for the question and the user confirms it. The user can add more advisors.

- When the user brings a decision ("should I...", "kya karu", pricing, hiring, raising money, a new product, a pivot, a family-business call), run `/roast-room`. For a quick question to one advisor, use `/roast-room ask <seat> ...`.
- Every advisor and the default board live in `.claude/skills/roast-room/roster.json`. When the user wants to add an advisor ("add Ratan Tata", "I want X on my board"), run `/newroaster`. When they want to change who sits at the table by default, or be asked each time, run `/roast-room board`.
- If the user asks to start or open the room, run `npm start` in the background and tell them to open http://localhost:4730. It needs Node 20 or newer and nothing else.
- Councils are saved in `sessions/<date>-<decision>/`. The room plays them live as those files land. Follow `.claude/skills/roast-room/references/live-room.md` exactly so the room can read them.
- The seats are simulations built from public work. Never present a seat's words as something the real person said unless it is a verbatim quote with a source id from that seat's brain.
- Write the Chair's parts in plain Hinglish (Roman script): short sentences, no hype, no filler. `--english` switches a run to plain English. Card field labels, verdict labels, and JSON keys stay in English because the room parses them. Money in ₹ with lakh and crore. Keep the verdict in chat short enough to decide from at a glance; the full report goes in `verdict.md`, and the room's "Download PDF" button turns it into a branded PDF.
- The original global seats (Bezos, Buffett, Hormozi, and the rest) and their example sessions are kept in `archive/` and are not in the roster. To bring one back, move its agent file and brain folder back and add it with `add_seat.mjs`.
